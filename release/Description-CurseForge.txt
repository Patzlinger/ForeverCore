![Forever Core UI](https://raw.githubusercontent.com/Patzlinger/ForeverCore/development/release/curseforge/00-header.jpg)

Forever Core UI is a complete user interface for **World of Warcraft: Forever**: frames, bars, nameplates, quests, bags, map, chat and tooltips in one calm look – flat and dark with gold accents. Every part is its own addon, so use all fifteen or only the ones you need.

![The whole interface](https://raw.githubusercontent.com/Patzlinger/ForeverCore/development/release/curseforge/03-interface.jpg)

![Why Forever Core UI? One interface, ready to play, built for Forever, works with Questie, Details!, Masque and TomTom](https://raw.githubusercontent.com/Patzlinger/ForeverCore/development/release/curseforge/05-why.jpg)

## Good to know
- Every addon needs the small base addon **ForeverCore** – it's included in the package.
- English and German. The screenshots were taken with the German client.
- No rotation help and no automation in combat.
- This is a **beta**. Found a bug? Please post it in the comments, ideally with the error text from **BugSack**.
