# Bilder der CurseForge-Beschreibung

Die Beschreibung (`release/Description-CurseForge.txt`) bindet diese Bilder direkt von GitHub ein
(`https://raw.githubusercontent.com/Patzlinger/ForeverCore/development/release/curseforge/<Datei>`).
So landen sie nicht in der CurseForge-Galerie.

- **Nicht umbenennen oder löschen** – sonst fehlen sie auf der CurseForge-Seite.
- Ein Bild austauschen: neue Datei unter **demselben Namen** speichern, committen, pushen. CurseForge zeigt sie nach
  kurzer Zeit (GitHub speichert Bilder einige Minuten zwischen).
- Die Karten werden aus den echten Screenshots im Stil der Website erzeugt (Spielernamen und Chat unkenntlich).
